# Гуров — Последний удовл

Офлайн-платформер на русском языке: профессор гонится за Иваном Павленко, сбежавшим с защиты диплома. Четыре главы, два босса, выбор улучшения, диалоги с озвучкой и анимированные вступление и финал. Все события и реплики вымышлены.

Игра написана на JavaScript и Canvas 2D. На Mac она работает в приложении с WKWebView; Windows-версия использует Electron. Для игры нужен компьютер с клавиатурой. Сенсорного управления пока нет.

## Быстрый запуск из исходников

Нужен **Python 3.9+**. Из корня проекта выполните:

```sh
python3 build.py --web-only
```

Затем откройте `game/index.html` в браузере. В Windows команда Python может называться `py -3`. Сервер, npm и интернет для запуска игры не нужны. Первый запуск требует подготовки ресурсов: сгенерированные копии картинок не хранятся в Git.

**На macOS:** двойной щелчок по `Играть.command` открывает собранное приложение, а при его отсутствии подготавливает и открывает браузерную версию. Чтобы собрать приложение, установите Xcode Command Line Tools и выполните:

```sh
python3 build.py
open "dist/Гуров — Последний удовл.app"
```

Команда создаёт приложение для Apple Silicon и Intel, macOS 12+. Запуск проверен на Apple Silicon; Intel и Windows требуют проверки на соответствующих устройствах.

## Управление

| Клавиши | Действие |
| --- | --- |
| A / D, стрелки | Движение |
| Пробел | Прыжок и второй прыжок |
| J / X | Бросить челюсть; можно удерживать |
| Shift / K | Рывок |
| E | Поговорить, прочитать заметку, поймать Ивана |
| H | Лечение бумагой после выбора улучшения |
| Esc / P | Пауза |
| M | Звук |

[Подробнее об игре и сохранениях](docs/PLAYING.md).

## Структура

```text
game/             игровой код, интерфейс и текущие ресурсы
  assets/         PNG-оригиналы игровых иллюстраций и готовые аудиобанки
native/           macOS-оболочка на Swift и генератор иконки
desktop/          Windows-оболочка Electron
tools/            подготовка ресурсов, состав дистрибутива, запуск тестов
tests/            проверки механик, браузерных сцен и маршруты прохождения
docs/             устройство проекта, разработка, источники ресурсов
project.json      название, версия приложения и закреплённый Electron
build.py          подготовка браузерной версии / сборка macOS
package_game.py   выпуск архивов для игроков
dist/             локальные приложения и архивы; не входит в Git
.build/           временные результаты сборки; не входит в Git
```

Начните с [карты модулей](docs/ARCHITECTURE.md). Команды тестирования и выпуск версий описаны в [руководстве разработчика](docs/DEVELOPMENT.md).

## Проверки

Для тестов нужен **Node.js 22+**. Зависимости закреплены в `package-lock.json`.

```sh
npm ci
npx playwright install chromium
python3 build.py --web-only
npm test
npm run check
npm run test:browser
npm run test:campaign
```

Браузерные проверки проходят без сети; обе ветки улучшений проверяются отдельными прохождениями. GitHub Actions запускает эти же проверки. Логи и снимки экранов создаются в `tests/.output/` и исключены из Git.

## Дистрибутивы и ресурсы

```sh
python3 package_game.py --target browser
```

Готовый архив появится в `dist/releases/`. Игрок распаковывает его и открывает `index.html` без Python. Другие платформы — в [руководстве по сборке](docs/DEVELOPMENT.md#дистрибутивы).

В репозитории хранятся текущие игровые иллюстрации и готовая озвучка. Исходные личные фотографии, голосовые записи, веса моделей, старые версии и видеомонтаж в него не входят. Иллюстрации для офлайн-запуска собираются из `game/assets/art-manifest.json`; генерация голосов не требуется.

[Источники и условия использования ресурсов](docs/ASSETS.md). Общая свободная лицензия на проект пока не назначена; отдельные условия ресурсов сохранены в атрибуции. Готовые архивы предназначены для GitHub Releases, а не для истории исходного кода.
