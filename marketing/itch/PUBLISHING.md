## Файлы версии 2.8.7

1. `dist/itch/Gurov-2.8.7-HTML5.zip` — отметить «This file will be played in browser».
2. `dist/releases/Gurov-2.8.7-Windows-x64.zip` — Windows.
3. `dist/releases/Gurov-2.8.7-macOS.zip` — macOS.
4. `dist/releases/Gurov-2.8.7-browser.zip` — скачиваемая браузерная версия для игры без интернета.
5. `videos/Gurov-Trailer-v3.mp4` — скачиваемый трейлер. Встроенный видеоблок itch.io требует YouTube/Vimeo URL; публикация на этих сервисах отдельно не выполнялась.

ZIP для встроенного проигрывателя отличается от обычного браузерного дистрибутива: `index.html` должен лежать в корне. В него включены файлы из `tools.release_files.runtime_files`, а также `SOURCES.txt` из `docs/ASSETS.md` и `READ-ME.txt` из `docs/PLAYING.md`. Перед упаковкой выполнить `tools.prepare_assets.prepare_assets`.

Проверенная упаковка HTML5: 66 файлов, 167.3 MiB после распаковки, самый большой файл 56.6 MiB. CRC и соответствие исходному runtime проверены. SHA-256: `240703f230eb2d0fc042f612faa78284cff331add89fe633f2428fff47442f3b`.

Ограничения itch.io: до 1000 файлов, до 500 MB после распаковки, до 200 MB на файл и длина пути не более 240 символов. Документация: https://itch.io/docs/creators/html5

## Проверка перед открытием доступа

Сначала сохранить Draft. Проверить, что описание сохранилось после перезагрузки, каждый файл закончил загрузку, платформы выбраны правильно, HTML5 архив распакован сервером без ошибки. Запустить игру через Run game, проверить меню, вступление, управление и паузу. В оформлении HTML5-страницы включить показ скриншотов (по умолчанию они могут быть скрыты). Затем сохранить Public и проверить доступность страницы без авторизации.

На момент подготовки материалов 14 сентября 2026 страница сохранена как Draft. Обложка, четыре скриншота, описание и метаданные загружены. Загрузка игровых сборок заблокирована itch.io до подтверждения email владельцем аккаунта. Публичный доступ ещё не включён.
